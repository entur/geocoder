See the API docs for more details.

v3 Autocomplete Endpoint

/v3/autocomplete

Search for places by name with autocomplete functionality.

Search for Oslo:
/v3/autocomplete?q=oslo
Search with limit of 5:
/v3/autocomplete?q=skøyen&limit=5
Search with focus point (lat, lon, radius in kilometres):
/v3/autocomplete?q=torget&lat=60.39&lon=5.32&radius=10

v3 Reverse Geocoding Endpoint

/v3/reverse

Find places near a specific coordinate.

Lookup Oslo Central Station:
/v3/reverse?lat=59.911&lon=10.753
Lookup with radius of 200 metres (radius is in kilometres, decimals accepted):
/v3/reverse?lat=59.911&lon=10.753&radius=0.2

v3 Place Lookup Endpoint

/v3/place

Look up places by ID. Accepts up to 100 comma-separated ids.

Lookup Oslo S:
/v3/place?ids=NSR:StopPlace:59872

v2 Endpoints (deprecated)

v2 is deprecated - new integrations should use v3. See the migration guide.

v2 Autocomplete Endpoint

/v2/autocomplete

Search for places by name with autocomplete functionality.

Search for Oslo:
/v2/autocomplete?text=oslo
Search with size limit of 5:
/v2/autocomplete?text=skøyen&size=5

v2 Reverse Geocoding Endpoint

/v2/reverse

Find places near a specific coordinate.

Lookup Oslo Central Station:
/v2/reverse?point.lat=59.911&point.lon=10.753
Lookup with radius of 200 metres (boundary.circle.radius is in kilometres, decimals accepted):
/v2/reverse?point.lat=59.911&point.lon=10.753&boundary.circle.radius=0.2
