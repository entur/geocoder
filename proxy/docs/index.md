# Geocoder Proxy

Geocoding and reverse geocoding for Norwegian addresses and points of interest.

## API Docs

[Api Docs](https://developer.entur.no/apis/geocoder)

## Example

```bash
curl "https://api.entur.io/geocoder/v3/autocomplete?q=Oslo+S"
```
